# Open Agent Architecture (OAA) - Deutsch

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](../../LICENSE)
[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)

**Open Agent Architecture (OAA)** ist ein produktionsbereites Open-Source-Architektur-Framework für die Entwicklung autonomer KI-Agentensysteme. Es implementiert die **12-Factor Agent-Prinzipien**, dynamisches Skill-Routing und prüfbare Multi-Agenten-DAG-Ausführung.

## 🚀 Hauptmerkmale

1. **12-Factor Agent-Prinzipien**: Klare Trennung von Kontrollschicht, Kontextbudgetierung und Verifizierungs-Gates.
2. **Dynamische Skill-Routing-Engine**: Absichtskomprimierung und Vorbedingungsspeicher.
3. **Sitzungs-Harness**: Blockierungsfreie Schnellpfadausführung und kryptografische Ausführungsbelege.
4. **Zero-Trust-Sicherheit**: Automatische Bereinigung von Zugangsdaten und Sandbox-Isolierung.
5. **Multi-Modell-Unterstützung**: Unterstützung für OpenAI GPT-5 / Codex, Claude, DeepSeek und lokale LLMs.
