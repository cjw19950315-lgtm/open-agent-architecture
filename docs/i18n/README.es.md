**Open Agent Architecture (OAA)** es un marco arquitectónico de código abierto para construir y gobernar sistemas de Agentes de IA autónomos de nivel de producción. Implementa los principios **12-Factor Agent**, enrutamiento dinámico de habilidades y ejecución DAG multi-agente auditable.

## 🚀 Características Principales

1. **Principios 12-Factor Agent**: Separación del Plano de Control, Gestión del Presupuesto de Contexto y Puertas de Verificación.
2. **Motor de Enrutamiento Dinámico**: Compresión de intenciones y memoria de precondiciones.
3. **Arnés de Sesión**: Ejecución de ruta rápida sin bloqueos y recibos criptográficos.
4. **Seguridad Zero-Trust**: Desinfección de credenciales y aislamiento en sandbox.
5. **Soporte Multi-Modelo**: Compatible con OpenAI GPT-5 / Codex, Claude, DeepSeek y LLMs locales.
