**Open Agent Architecture（OAA）** は、自律型 AI エージェントシステムのためのプロダクションレベルのオープンソースアーキテクチャフレームワークです。**12-Factor Agent 原則**、動的スキルルーティング、監査可能なマルチエージェント DAG 実行を実装しています。

## 🚀 主な機能

1. **12-Factor Agent 原則**：統制プレーン、コンテキスト予算管理、検証ゲートの明確な分離。
2. **動的スキルルーティング**：意図圧縮アルゴリズムと事前条件メモリ。
3. **セッションハーネス**：非ブロッキング高速パス実行と暗号化実行レシート。
4. **ゼロトラストセキュリティ**：認証情報の自動マスキングとサンドボックス分離。
5. **マルチモデル対応**：OpenAI GPT-5 / Codex、Claude、DeepSeek、ローカル LLM をサポート。
